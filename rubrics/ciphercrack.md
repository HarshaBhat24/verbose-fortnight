# CipherCrack Cryptography Toolkit Rubric

- Cryptographic Algorithm Mechanics: Technical mechanics, key generation, and mathematical principles of 9 ciphers (Caesar, Affine, Atbash, Baconian, Vigenère, Monoalphabetic, Hill, Four Square, ROT13)
- Mathematical Foundations: Linear algebra, modular arithmetic, matrix multiplication, matrix inversion (modulo 26), modular multiplicative inverses, determinants, and key validation
- Cryptanalysis & Brute Force: Automated Caesar key space brute-forcing, frequency analysis, key space exploration, and automated ciphertext breaking
- Python CLI & Modular Architecture: Python argparse menu-driven CLI design, modular code structure, exception handling, and reusable cipher modules
- CTF Application: Utilizing custom cryptanalysis tooling during 10+ CTF competitions for rapid decryption and flag extraction
