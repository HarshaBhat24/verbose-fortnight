# Authorized Black-Box Web Application Security Assessment Rubric

- OWASP WSTG Methodology: Executing black-box reconnaissance, endpoint mapping, active enumeration (ffuf, Gobuster), and attack surface discovery
- Authentication & JWT Analysis: Evaluating JWT token structure, signature validation, session behavior, and authentication flow integrity
- Broken Object-Level Authorization (BOLA): Manual request modification, parameter manipulation, and validating tenant data boundaries
- Secret Management & Credential Exposure: Identifying sensitive OAuth client credentials exposed within client-side JavaScript assets
- WebSocket Security & CORS Review: Manual WebSocket connection testing using wscat, validating origin checks, CORS headers, and WebSocket authentication enforcement
- Penetration Testing Reporting: Independent authoring of professional penetration testing reports containing executive summaries, technical proof-of-concept attack chains, CVSS v3.1 scoring, and secure architecture recommendations
